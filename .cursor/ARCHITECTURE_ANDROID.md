# OmniTrace Android 采集蓝图（细节）

> **公开副本**：[`docs/architecture/android.md`](../docs/architecture/android.md)。
> **地位**：专门蓝图。总览与非目标见 `.cursor/ARCHITECTURE_BLUEPRINT.md` §8 / §7。  
> `omnitrace_android` 本期**不进** Windows OmniPlayer；**当前几乎不可用**。拷到 PC 时作旁路根。局域网联动见主蓝图 §7「以后」。

---

## 1. 进程与数据根

- 自用边载 APK；进程内模组（`info` / `start` / `tick` / `stop`）；通知栏前台服务常驻。无障碍与采集同一进程。
- 本机数据根：App 外部目录 `OmniDatabase/`。拷到电脑时放 `OmniDatabase/sources/<android_id>/`（**旁路根**），不改 Windows 现有布局。
- 信封与桌面相同：`{ v:1, module, ts, kind, payload }`；`module` 为**字符串**（勿写入 Windows `ModuleId`）。日历路径同 Century/Year/Month。
- 高频：`EventData/.../imu_DD.bin`（`OTIM` v1，禁止写 `trace_DD.bin`）。其余 `ModuleData/<id>/.../events_DD.jsonl`。
- 健康：`control/module_health.jsonl` 的 `start` / `beat`(约 2s) / `tombstone`。`manifest.json` 含 `source=android` 与 `device_id`。

## 2. 壳（Android 自有，非 OmniPlayer）

底栏三页，默认设置：

- **设置首页** = **采集总开关**（采集中/已停止）+ **采集情况直观可视化**（独立强调卡片与徽标；传感器级思维导图）+ 外观三档 + 子页入口：采集与权限 / 采集数据管理 / 地图资源管理 / 关于。
- **采集情况直观可视化** = 传感器级思维导图（左：元件名+型号参数+行间细线；中：圆+图标；右：数据说明；无硬件极淡灰、缺权限半透明可点进采集与权限；汇入「手机数据库」再连播放器/时间轴/地图/统计图表/畅想节点；可缩放平移带惯性、有边界；点左侧名称看科普）。
- **采集与权限**：最大档/开机自启/后台常驻/权限 + 各采集分模组拨动开关（关了下次开始采集才不注册）。
- **采集数据管理**：先显示上次体积再后台重扫，不统计地图瓦片；含电脑 IP/端口同步。
- **地图资源管理**：先进页再扫缓存。
- **关于**：写统计口径。
- 设置子页从右侧滑入（cubic-bezier 缓出）。壳配色对齐电脑 OmniPlayer。

## 3. 仪表盘（Android）

- **统计图表**：今日/近七日/**近三十天**/近十二月＝在录∩亮屏∩开锁时长；下为所选时段分应用；今日数字右侧「明细」滑入屏幕明细页。
- **睡眠猜测**：手机灭屏+未晃动；联动电脑时键鼠空闲 ≥10min 代理；±30min 校准；醒后 30min 应用顺序；页内 5 分钟双色活跃条；可局域网拉 PC `input_hist`，支持 `IP:端口`，需 cleartext。
- 时间轴：平移/缩放手势带惯性摩擦缓动；窗口行灰影＝不可能有焦点屏幕（没在录/灭屏/锁屏/无障碍没开）；时间轴绘图不跟顶栏显隐挪位；程序轴不再把剩余 App 合成「其他」。
- Canvas 口径：灰灭屏 / 蓝亮屏 / 绿开锁；音频占用；程序轴亮屏∩开锁。洗数视窗垫 1 屏。
- GPS 行踪只在仪表盘（地图折线/停留点，不列文字；地址反查异步）。行踪放大到未下载的城可弹整城体积。远距（世界比屏幕小）画正射球体（z0/z1 一张图贴 mesh，不是 3D 引擎）。瓦片 OkHttp 连接池、可见优先。时间轴与行踪全屏，点一下渐隐顶栏底栏。

---

## 4. 播放器（Android）

- 选日回放：按 `ui_map` 窗栈重建当时屏幕（黑底舞台，像看录屏，**不是** GPS 地图，也**不截视频**）；底栏时间轴 + 当时屏幕/应用。

---

## 5. 模组清单

| 模组 | 要点 |
|------|------|
| `hw` | 启动身份扫描；签名不变只写 `hw_unchanged`「组件信息无变化」 |
| `device` | 亮灭屏/电量/亮度/`keyguard` + 振动/NFC/红外忙闲钩子 |
| `imu` | 高频 bin；默认过夜档：亮屏 50Hz / 灭屏降；最大档默认关 |
| `env` | 环境 |
| `gps` | 行踪（仪表盘地图侧） |
| `perf` | 性能 |
| `radio` | 状态变化，默认不持续扫描 |
| `media` | 音频/相机**占用**，不要 PCM/预览 |
| `app_focus` | 应用焦点 |
| `touch` | 交互事件，非原始轨迹 |
| `ui_map` | 显示器几何 + 窗栈 + 焦点浅树 |

---

## 6. 非目标（手机，与主蓝图 §7 对齐）

不上架、不录麦克风 PCM / 相机预览 / 截视频、不做跑分、不共用 Windows `trace_DD.bin`、不改 Windows `ModuleId` 闭枚举；OmniPlayer 暂不播手机源。
