OmniTrace（Windows）
====================

这是什么
  在这台电脑上记录和回放你用过的窗口、鼠标和键盘，并带本机笔记。
  数据只存在这台电脑上，不会上传。

推荐：安装到本机
  1. 解压整个文件夹（不要只拿出一个 exe）
  2. 双击「安装到本机.bat」
  3. 用桌面上的 OmniTrace 打开

  程序位置：%LOCALAPPDATA%\OmniTrace
  数据位置：%USERPROFILE%\OmniTrace\OmniDatabase
  卸载（Windows 设置 → 应用 → OmniTrace）不会删除数据。

也可以不安装
  双击「启动 OmniPlayer.bat」。
  没有安装指针时，数据写到用户目录下的 OmniTrace\OmniDatabase。
  若你以前已经在「下载\OmniTrace」里有一份库，会继续用那一份。

Windows 提示「未知应用 / 已保护你的电脑」
  安装包目前没有代码签名。选「更多信息」→「仍要运行」。
  若双击没有反应：右键 exe → 属性 → 勾选「解除锁定」。

请不要
  不要把键盘记录文件发给网上的 AI（里面会有密码、私信、验证码）。
  不要把整个 OmniDatabase 文件夹发到网上或推进 Git。

系统
  Windows 10 或 11，64 位。需要 Microsoft Edge WebView2（一般已自带）。

---

What this is
  Capture and replay windows, mouse, and keyboard on this PC, plus local notes.
  Data stays on this computer. Nothing is uploaded.

Install (recommended)
  Unzip the whole folder, then run 安装到本机.bat (Install on this PC).
  App: %LOCALAPPDATA%\OmniTrace
  Data: %USERPROFILE%\OmniTrace\OmniDatabase
  Uninstalling the app does not delete your data.

Run without installing
  Double-click 启动 OmniPlayer.bat. Data goes under your user folder
  OmniTrace\OmniDatabase unless an older library already exists.

Windows SmartScreen
  The build is unsigned. More info → Run anyway.
  If nothing happens: Properties on the exe → Unblock.

Do not send keyboard capture files to any cloud model, and do not upload OmniDatabase.
